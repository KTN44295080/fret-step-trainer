# 「人生オーバー」「惑う星」長さ・拍子一覧

## 計算条件

この文書の長さは、FRET STEPに登録されている譜面の総小節数、原曲BPM、拍子表から計算した**譜面再生範囲の理論値**です。

- BPMは全区間で一定として計算
- 1拍は四分音符
- カウントインは含まない
- 動画先頭の余白や末尾の無音は含まない
- 長さの式は`総拍数 × 60 ÷ BPM`

## 人生オーバー

### 基本情報

- 原曲テンポ: 170 BPM
- 総小節数: 156小節
- 拍子: 全小節4/4
- 1小節: 4拍
- 総拍数: `156 × 4 = 624拍`
- 長さ: `624 × 60 ÷ 170 = 220.235294...秒`
- 時分秒: **約3分40.235秒**

拍子変更はありません。

## 実装用の拍子表

「人生オーバー」は全小節4/4なので、例外表は空です。

```js
const lifeOverMeterMap = {};
```

「惑う星」は次の小節だけ分子を上書きし、未指定の小節は4/4として扱います。

```js
const madowMeterMap = {
  18: 6,
  117: 5,
  118: 5,
  119: 5,
  120: 6,
  121: 5,
  122: 5,
  123: 5,
  124: 6,
};
```

```js
function beatsForMeasure(measure, meterMap = {}) {
  return meterMap[measure] ?? 4;
}
```
